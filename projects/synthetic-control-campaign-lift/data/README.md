# Data Download Instructions

```bash
# Install Kaggle CLI if needed
pip install kaggle

# Download Marketing Campaign Performance Dataset (200K rows)
kaggle datasets download -d manishabhatt22/marketing-campaign-performance-dataset -p .
unzip marketing-campaign-performance-dataset.zip -d .
```

## Expected Files

- `marketing_campaign_dataset.csv` — 200K rows, 2 years of campaign data
